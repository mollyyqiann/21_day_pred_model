# Burst Predictions — Morning (Pre-Market)

Cross-sectional pre-market burst prediction: which calm large-cap stocks are unusually likely to deliver a sustained 1–5 day pop right now? Sent every weekday morning before open.

## Schedule
- **Mon–Fri 08:45 ET** (pre-market).
- Plist: [`scheduler/com.user.burstpredict.plist`](../../scheduler/com.user.burstpredict.plist).
- Script: [`code/29_burst_daily_runner.py`](../../code/29_burst_daily_runner.py).

## Model (current production)
- **v6 augmented classifiers** (NOT v1 / v3 — those are research milestones in the historical reports here).
- Two universes:
  - **v4** universe: SP500, price > $40, 60d realized vol 5–30% annualized — trained as `models/burst_gbc_v6b_augmented.joblib`
  - **v5** universe: upside-asymmetric variant — trained as `models/burst_gbc_v6_augmented.joblib`
- Three regression heads per universe predicting **1d / 3d / 5d** expected return: `models/burst_reg_v6{,b}_fwd_{1d,3d,5d}.joblib`.
- Target: a "burst" = within next 5 trading days, some 2–5-day window averages ≥ 4%/day.
- Live enrichment at inference: pre-market price (Yahoo, ~15-min lag), overnight news.
- Self-evaluation: yesterday's predictions are graded against now-observable returns; hit-rates and MAE included in the message.

## Output
- **Notification** (Telegram or iMessage per `config/burst_daily.json`'s `notifier` field). See [`29_burst_daily_runner.py:1`](../../code/29_burst_daily_runner.py:1) docstring for example body.
- Daily JSON log: `output/daily_log/{YYYY-MM-DD}.json`.
- Logs: `output/daily_log/launchd.{stdout,stderr}.log`.

## Hold horizon
- **1–5 day** position. The classifier flags a burst-prone setup; the regression heads give expected returns at 1d / 3d / 5d.
- This is a **short-horizon** model — not a multi-week hold like the Monthly Gainer model.

## Distinguishing features (vs other systems)
- **Pre-market** (08:45 ET) — only system that runs before the open.
- **5-day burst horizon** — short-term momentum/pop predictions.
- **Calm-stock universe** (5–30% vol) — explicitly excludes already-volatile names.
- **Top-N notifications** (typically top-5 per universe).
- Companion to **drop_alert** which runs ~35 min later at 09:20 and consumes today's burst log.

## Note on model lineage
The historical reports describe v1 (no longer used), v3 (no longer used), and the production today is v6 augmented. There's also a v11 retrain pipeline (monthly, 1st of each month at 03:00 — see [`scheduler/com.user.v11retrain.plist`](../../scheduler/com.user.v11retrain.plist)) that may eventually replace v6. Don't confuse "v6 burst" with "v3 monthly_gainer" (root [`MONTHLY_GAINER_REPORT.md`](../../MONTHLY_GAINER_REPORT.md)) — they are different models with different targets, universes, and horizons.
